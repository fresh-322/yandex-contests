Задача G: 4 элемента с суммой 0

Условие задачи (pdf)

Дано четыре списка целых чисел A, B, C и D одинаковой длины n. Посчитайте количество четверок целых чисел (x,y,z,t) (1≤x,y,z,t≤n) таких, что Ax+By+Cz+Dt=0.
Формат входных данных

Первая строка содержит целое число n — количество чисел в списках (1≤n≤2500). Следующие n строк содержат четверки целых чисел Ai, Bi, Ci, Di — i-е элементы каждого из четырех списков. Все элементы по абсолютному значению не превосходят 228.
Формат выходных данных

В единственной строке выведите ответ на данную задачу.
