Задача I: Поиск подмассива со сдвигом

Условие задачи (pdf)

Даны два массива a и b, состоящие из натуральных чисел. Требуется найти все вхождения второго массива в первый с точностью до сдвига на какое-то целое число. Формально, корректным вхождением является индекс l такой, что для каждого индекса i∈[l,l+k) a[l+i]=b[i]+d, где d - целое число, фиксированное для всех i.
Формат входных данных

В первой строке входного файла даны два числа n, k (1≤n,k≤105) "— длины первого и второго массивов соответственно. Во второй строке входного файла даны n чисел ai через пробел, а в третьей строке - k чисел bi, описывающие элементы массивов (0≤ai,bi≤109).
Формат выходных данных

В единственной строке выходного файла выведите все индексы вхождений в возрастающем порядке. Числа требуется выводить через пробел.
